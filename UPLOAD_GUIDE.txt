# How to Deploy Your Bot to Railway

## Files to upload to GitHub (all 4):
- bot.py
- requirements.txt
- Procfile
- runtime.txt

## Steps:

1. Go to https://github.com → sign in → click "+" → New repository
2. Name it "discord-bot" → click "Create repository"
3. Drag and drop ALL 4 files into the GitHub page → click "Commit changes"

4. Go to https://railway.app → New Project → Deploy from GitHub repo
5. Select your "discord-bot" repository

6. Click your project → Variables tab → New Variable:
   - Name:  DISCORD_BOT_TOKEN
   - Value: (paste your token here)

7. Click Deploy — your bot will be online in ~1 minute!

## Important:
- Only add the ONE variable above (DISCORD_BOT_TOKEN)
- Ignore any "suggested variables" Railway shows you
- The bot stays online 24/7 even when your PC is off
